06 Deploy package for Ionos

A launch-ready copy of the site now lives in deploy-couk/. It is _deploy/ with every pulsefulfilment.com reference (416 across canonicals, og:url, JSON-LD, sitemap, robots) swapped to pulsefulfilment.co.uk, plus a 404.html and an .htaccess containing 75 exact 301 rules, pattern rules for WordPress archives, https + non-www canonical host, and 410s for wp-admin/wp-login/xmlrpc.

07 Cutover steps on Ionos

  1. Back up WordPress. Ionos → Hosting → Backup, or export via your host panel (files + database). Keep it for at least a month.
  2. Lower DNS TTL on the .co.uk A record to 300s, one day before launch (Ionos → Domains → DNS).
  3. Wire up forms. Contact and Get pricing forms need a static-friendly endpoint (Formspree, Ionos form mailer, or your CRM embed). Test a submission before going live.
  4. Upload to a staging folder first. Via SFTP, put deploy-couk/ contents in a subfolder or a temporary subdomain, click through every page, and run the redirect test list from the CSV.
  5. Swap the webroot. Rename the WordPress folder (keep it), move deploy-couk/ contents to the domain's root, including the hidden .htaccess. Delete the old WordPress .htaccess so it doesn't conflict.
  6. SSL. Ionos SSL should carry over on the same domain; confirm https loads and http redirects.
  7. Don't touch MX records. Email stays on Ionos — only the A/CNAME for web changes, if at all.
  8. Search Console. Submit https://pulsefulfilment.co.uk/sitemap.xml, request indexing of the homepage, and watch the Pages report for 404s for six weeks.
  9. Decommission. After 30 days clean, delete the renamed WordPress folder and its database, and cancel WordPress plugins/licences.
